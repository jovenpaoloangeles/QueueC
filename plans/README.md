## Findings considered and rejected

So nobody re-audits these:

- **No auth / multi-session**: maintainer-parked (ROADMAP.md "Parked"). Plan 001's CORS removal is request-authenticity hygiene, not auth.
- **React 19 / Vite major upgrades**: no present cost; ecosystem-pressure-driven. Revisit when a dependency demands it.
- **Aligning the four `version` fields to the CHANGELOG**: do it in the commit that cuts v1.8, not as standalone work.
- **Switching `test:unit` to `bun test` auto-discovery**: kept the explicit chain (plan 002 extends it); bun-test runner semantics with assert-style files are unverified here.
- **SQLite indexes**: every query filters `session_id` on tables of hundreds of rows — not worth it at club scale.
- **Docker healthcheck / SSE backoff / PWA**: open ROADMAP items, deliberate sequencing by the maintainer, not audit findings.
- **`queuec.db` / `players.json` committed?**: checked — all gitignored; `players.example.json` and fixtures contain synthetic names only.
- **SmartQueue/SQL/security sweeps**: clean — parameterized SQL throughout, SSE lifecycle sound, money math integer-safe, Dockerfile non-root with healthcheck.
- **"Winner-only" result (tap the winner, skip the loser's score)** — declined by the maintainer (2026-11-26); both scores stay required.
- **Session on/off setting for the deck auto-refill** — not requested; the maintainer asked for the deck to refill itself unconditionally. Marked in code with a `ponytail:` note; add a per-session setting if a queue master who builds lineups by hand needs the old behaviour.
- **Refilling on ▶ Start now, ✕ Cancel or a late check-in; auto-starting from an empty deck** — excluded on purpose: a lineup the QM removed or sent out by hand must not be re-planned behind their back, and an idle court is already covered by the idle-court nudge.
- **Keeping a Smart Match preview dialog** — it duplicated the review the deck cards already give; a 15 s Undo replaces it. If accidental starts become a problem, confirm only when the plan starts court matches.
- **Last-call warning sized to the session's points** — `LAST_CALL_SECS` (`client/src/lib/utils.js`) stays a fixed 20 min; its own `ponytail:` note names the upgrade.

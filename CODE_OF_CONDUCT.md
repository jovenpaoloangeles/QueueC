# Code of Conduct

## Our pledge

Everyone participating in this project — issues, PRs, reviews, chat — is
expected to be respectful and constructive. We're here to run badminton
sessions, not to fight.

## Standards

Behavior that contributes to a positive environment:

- Assume good faith; assume people have different skill levels.
- Give and accept technical feedback on the merits.
- Keep it about the code and the product, never the person.

Unacceptable behavior: harassment, personal attacks, trolling, publishing
others' private information, or any conduct that would get you benched at an
actual badminton session.

## Enforcement

Report problems by opening a private GitHub security advisory or contacting
the maintainer via their GitHub profile. Maintainers may delete, edit, or
reject contributions and communication that violate this standard.

This code of conduct adapts the Contributor Covenant's spirit; the full
covenant is at https://contributor-covenant.org.

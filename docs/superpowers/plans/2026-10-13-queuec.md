# QueueC Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local badminton queue manager web app where a queue master manages players, courts, and match flow from a single laptop-optimized screen.

**Architecture:** Express REST API + SSE backend with SQLite, served alongside a React/Vite SPA. All state lives in SQLite; the frontend polls nothing — it receives pushes via SSE and updates timers locally. The root `package.json` runs both processes via `concurrently`.

**Tech Stack:** Node.js 20+, Express 4, better-sqlite3, React 18, Vite 5, concurrently

## Global Constraints

- SQLite file: `queuec.db` at project root (gitignored)
- All timestamps: Unix seconds (integer), use `Math.floor(Date.now() / 1000)` — never milliseconds
- Skill levels (ordered): `newbie=1 beginner=2 intermediate=3 upper_intermediate=4 advanced=5`
- Timer formula — waiting seconds: `NOW − checked_in_at − total_seconds_played`
- Theme: dark slate — base `#0a0f1a`, surface `#0f172a`, border `#1e293b`, active court accent `#4ade80`, selection accent `#1d4ed8`, text primary `#f1f5f9`, text muted `#64748b`
- Monospace font stack: `'JetBrains Mono', 'Fira Code', monospace`
- API base: `http://localhost:3001` (server); client served at `http://localhost:3000` (Vite)
- No auth, no HTTPS required

### Task 2: Database Layer

**Files:**
- Create: `server/db.js`

**Interfaces:**
- Produces: `import db from './db.js'` — `db` is a `better-sqlite3` Database instance with all four tables created. `db` is the single export; all routes import it directly and use prepared statements.

- [ ] **Step 1: Create server/db.js**

```js
import Database from 'better-sqlite3'
import { join, dirname } from 'path'
import { fileURLToPath } from 'url'

const __dirname = dirname(fileURLToPath(import.meta.url))
const db = new Database(join(__dirname, '../queuec.db'))

db.pragma('journal_mode = WAL')
db.pragma('foreign_keys = ON')

db.exec(`
  CREATE TABLE IF NOT EXISTS players (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    skill_level TEXT NOT NULL CHECK(skill_level IN ('newbie','beginner','intermediate','upper_intermediate','advanced')),
    created_at INTEGER NOT NULL
  );

  CREATE TABLE IF NOT EXISTS sessions (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    scheduled_start INTEGER NOT NULL,
    scheduled_end INTEGER NOT NULL,
    court_count INTEGER NOT NULL DEFAULT 2,
    started_at INTEGER NOT NULL,
    ended_at INTEGER
  );

  CREATE TABLE IF NOT EXISTS queue_entries (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id INTEGER NOT NULL REFERENCES sessions(id),
    player_id INTEGER NOT NULL REFERENCES players(id),
    checked_in_at INTEGER NOT NULL,
    status TEXT NOT NULL DEFAULT 'waiting' CHECK(status IN ('waiting','playing','resting','left')),
    last_played_at INTEGER,
    total_seconds_played INTEGER NOT NULL DEFAULT 0
  );

  CREATE TABLE IF NOT EXISTS matches (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    session_id INTEGER NOT NULL REFERENCES sessions(id),
    court_number INTEGER NOT NULL,
    format TEXT NOT NULL CHECK(format IN ('singles','doubles')),
    team1_p1 INTEGER NOT NULL REFERENCES queue_entries(id),
    team1_p2 INTEGER REFERENCES queue_entries(id),
    team2_p1 INTEGER NOT NULL REFERENCES queue_entries(id),
    team2_p2 INTEGER REFERENCES queue_entries(id),
    team1_score INTEGER,
    team2_score INTEGER,
    started_at INTEGER NOT NULL,
    ended_at INTEGER
  );
`)

export default db
```

import { Router } from 'express'
import db from '../db.js'

const router = Router()

router.post('/sessions/:id/checkin', (req, res) => {
  const { player_id } = req.body
  const now = Math.floor(Date.now() / 1000)
  // Prevent duplicate checkin in same session
  const existing = db.prepare(
    'SELECT id FROM queue_entries WHERE session_id = ? AND player_id = ?'
  ).get(req.params.id, player_id)
  if (existing) return res.status(409).json({ error: 'Player already checked in' })

  const { lastInsertRowid } = db.prepare(
    'INSERT INTO queue_entries (session_id, player_id, checked_in_at) VALUES (?, ?, ?)'
  ).run(req.params.id, player_id, now)
  const entry = db.prepare('SELECT * FROM queue_entries WHERE id = ?').get(lastInsertRowid)
  res.status(201).json({ entry })
})

router.patch('/queue/:entryId/status', (req, res) => {
  const { status } = req.body
  db.prepare('UPDATE queue_entries SET status = ? WHERE id = ?').run(status, req.params.entryId)

### Task 5: Matches API

**Files:**
- Modify: `server/routes/matches.js`

**Interfaces:**
- Consumes: `db` from `../db.js`
- Produces:
  - `POST /api/matches` body `{ session_id, court_number, team1_p1, team1_p2|null, team2_p1, team2_p2|null }` → `{ match }`; also sets all involved `queue_entries.status = 'playing'`; format auto-derived: `team1_p2 === null ? 'singles' : 'doubles'`
  - `PATCH /api/matches/:id/end` body `{ team1_score, team2_score }` → `{ match }`; also sets `queue_entries.status = 'waiting'`, updates `last_played_at` and increments `total_seconds_played` for all players

- [ ] **Step 1: Implement server/routes/matches.js**

```js
import { Router } from 'express'
import db from '../db.js'

const router = Router()

router.post('/', (req, res) => {
  const { session_id, court_number, team1_p1, team1_p2, team2_p1, team2_p2 } = req.body
  const now = Math.floor(Date.now() / 1000)
  const format = team1_p2 ? 'doubles' : 'singles'

  const { lastInsertRowid } = db.prepare(`
    INSERT INTO matches (session_id, court_number, format, team1_p1, team1_p2, team2_p1, team2_p2, started_at)
    VALUES (?, ?, ?, ?, ?, ?, ?, ?)
  `).run(session_id, court_number, format, team1_p1, team1_p2 ?? null, team2_p1, team2_p2 ?? null, now)

  // Mark all involved players as playing
  const playerEntryIds = [team1_p1, team1_p2, team2_p1, team2_p2].filter(Boolean)
  const setPlaying = db.prepare('UPDATE queue_entries SET status = ? WHERE id = ?')
  for (const id of playerEntryIds) setPlaying.run('playing', id)

  const match = db.prepare('SELECT * FROM matches WHERE id = ?').get(lastInsertRowid)
  res.status(201).json({ match })
})

router.patch('/:id/end', (req, res) => {
  const { team1_score, team2_score } = req.body
  const now = Math.floor(Date.now() / 1000)

  const match = db.prepare('SELECT * FROM matches WHERE id = ?').get(req.params.id)
  if (!match) return res.status(404).json({ error: 'Match not found' })

  const duration = now - match.started_at

  db.prepare(
    'UPDATE matches SET team1_score = ?, team2_score = ?, ended_at = ? WHERE id = ?'
  ).run(team1_score, team2_score, now, req.params.id)

  // Update queue entries: back to waiting, last_played_at, total_seconds_played
  const playerEntryIds = [match.team1_p1, match.team1_p2, match.team2_p1, match.team2_p2].filter(Boolean)

```js
const SKILL_MAP = { newbie: 1, beginner: 2, intermediate: 3, upper_intermediate: 4, advanced: 5 }

function waitSeconds(entry) {
  const now = Math.floor(Date.now() / 1000)
  return now - entry.checked_in_at - entry.total_seconds_played
}

function skillValue(entry) {
  return SKILL_MAP[entry.skill_level] ?? 3
}

// For singles: return the 2 entries with longest wait
// For doubles: find 4-player combo maximising total wait while minimising |avgSkill(t1) - avgSkill(t2)|
// Returns [team1_p1_id, team1_p2_id|null, team2_p1_id, team2_p2_id|null]
export function suggestPlayers(entries, mode) {
  const waiting = entries
    .filter(e => e.status === 'waiting')
    .map(e => ({ ...e, wait: waitSeconds(e), skill: skillValue(e) }))
    .sort((a, b) => b.wait - a.wait)

  if (waiting.length < (mode === 'singles' ? 2 : 4)) return []

  if (mode === 'singles') {
    return [waiting[0].id, null, waiting[1].id, null]
  }

  // Doubles: try all C(n,4) combos, pick best score
  // ponytail: O(n⁴) scan — fine for ≤30 players, switch to heuristic if n grows
  const SKILL_WEIGHT = 10
  let best = null
  let bestScore = -Infinity

  for (let i = 0; i < waiting.length; i++) {
    for (let j = i + 1; j < waiting.length; j++) {
      for (let k = j + 1; k < waiting.length; k++) {
        for (let l = k + 1; l < waiting.length; l++) {
          const [a, b, c, d] = [waiting[i], waiting[j], waiting[k], waiting[l]]
          // Try both team splits: (a+b vs c+d) and (a+c vs b+d)
          for (const [t1, t2] of [[[a,b],[c,d]], [[a,c],[b,d]]]) {
            const totalWait = [...t1,...t2].reduce((s, e) => s + e.wait, 0)
            const skillDiff = Math.abs(
              (t1[0].skill + t1[1].skill) / 2 - (t2[0].skill + t2[1].skill) / 2
            )
            const score = totalWait - skillDiff * SKILL_WEIGHT
            if (score > bestScore) {
              bestScore = score
              best = [t1[0].id, t1[1].id, t2[0].id, t2[1].id]
            }
          }
        }
      }
    }
  }
  return best ?? []
}
```

import { Router } from 'express'
import db from '../db.js'

const router = Router()
const clients = new Set()

export function broadcast() {
  if (clients.size === 0) return
  const payload = currentState()
  const data = `event: state\ndata: ${JSON.stringify(payload)}\n\n`
  for (const res of clients) res.write(data)
}

function currentState() {
  const session = db.prepare(
    'SELECT * FROM sessions WHERE ended_at IS NULL ORDER BY started_at DESC LIMIT 1'
  ).get() ?? null

  if (!session) return { session: null, queue: [], activeMatches: [], stats: null }

  const queue = db.prepare(
    "SELECT qe.*, p.name, p.skill_level FROM queue_entries qe JOIN players p ON p.id = qe.player_id WHERE qe.session_id = ? AND qe.status != 'left' ORDER BY qe.checked_in_at"
  ).all(session.id)

  const activeMatches = db.prepare(
    'SELECT * FROM matches WHERE session_id = ? AND ended_at IS NULL'
  ).all(session.id)

  const now = Math.floor(Date.now() / 1000)
  const waiters = queue.filter(e => e.status === 'waiting')
  const avg_wait_seconds = waiters.length
    ? Math.round(waiters.reduce((s, e) => s + (now - e.checked_in_at - e.total_seconds_played), 0) / waiters.length)
    : 0

  const match_count = db.prepare(
    'SELECT COUNT(*) as c FROM matches WHERE session_id = ? AND ended_at IS NOT NULL'
  ).get(session.id).c

  const leaderboard = db.prepare(`
    SELECT p.id as player_id, p.name,
      SUM(CASE
        WHEN (m.team1_p1 = qe.id OR m.team1_p2 = qe.id) AND m.team1_score > m.team2_score THEN 1
        WHEN (m.team2_p1 = qe.id OR m.team2_p2 = qe.id) AND m.team2_score > m.team1_score THEN 1
        ELSE 0 END) as wins
    FROM matches m
    JOIN queue_entries qe ON (qe.id = m.team1_p1 OR qe.id = m.team1_p2 OR qe.id = m.team2_p1 OR qe.id = m.team2_p2)
    JOIN players p ON p.id = qe.player_id
    WHERE m.session_id = ? AND m.ended_at IS NOT NULL
    GROUP BY p.id ORDER BY wins DESC LIMIT 5
  `).all(session.id)

  return {
    session,
    queue,
    activeMatches,
    stats: { player_count: queue.length, match_count, avg_wait_seconds, leaderboard },
    serverTime: now
  }
}

router.get('/', (req, res) => {

  res.write(`event: state\ndata: ${JSON.stringify(currentState())}\n\n`)

})

import { useState, useEffect } from 'react'

export function useTimers(serverTime, queue, activeMatches) {
  const [tick, setTick] = useState(0)

  useEffect(() => {
    const id = setInterval(() => setTick(t => t + 1), 1000)
    return () => clearInterval(id)
  }, [])

  const now = (serverTime ?? Math.floor(Date.now() / 1000)) + tick

  const waitSeconds = new Map()
  for (const e of queue ?? []) {
    if (e.status === 'waiting') {
      waitSeconds.set(e.id, Math.max(0, now - e.checked_in_at - e.total_seconds_played))
    }
  }

  const playSeconds = new Map()
  for (const m of activeMatches ?? []) {
    playSeconds.set(m.id, Math.max(0, now - m.started_at))
  }

  return { waitSeconds, playSeconds }
}

import { useState, useEffect } from 'react'
import PlayerCard from './PlayerCard.jsx'
import { checkinPlayer, getPlayers, getSuggestion } from '../api.js'

export default function QueueGrid({ session, queue, waitSeconds, selection, onSelectionChange }) {
  const [mode, setMode] = useState('smart')
  const [allPlayers, setAllPlayers] = useState([])
  const [showCheckin, setShowCheckin] = useState(false)

  useEffect(() => { getPlayers().then(d => setAllPlayers(d.players)) }, [])

  // Apply smart suggestion when mode switches to smart or queue changes
  useEffect(() => {
    if (mode !== 'smart' || !session) return
    const waiting = queue.filter(e => e.status === 'waiting')
    const modeStr = waiting.length >= 4 ? 'doubles' : 'singles'
    getSuggestion(session.id, modeStr).then(d => {
      if (d.suggestion?.length) onSelectionChange(d.suggestion.filter(Boolean))
    })
  }, [mode, queue.length, session?.id])

  function toggleSelect(entryId) {
    if (selection.includes(entryId)) {
      onSelectionChange(selection.filter(id => id !== entryId))
    } else if (selection.length < 4) {
      onSelectionChange([...selection, entryId])
    }
  }

  const waiting = queue.filter(e => e.status === 'waiting')
  const notInSession = allPlayers.filter(p => !queue.some(e => e.player_id === p.id))

  return (
    <div style={{ fontFamily: 'inherit', fontSize: 11 }}>
      <div style={{ display: 'flex', justifyContent: 'space-between', alignItems: 'center', marginBottom: 6 }}>
        <span style={{ color: '#334155', fontSize: 9, textTransform: 'uppercase', letterSpacing: 1 }}>

'#60a5fa' : '#334155', border: `1px solid ${mode === 'smart' ? '#1d4ed8' : '#1e293b'}`, borderRadius: 3, padding: '2px 6px', fontSize: 8, cursor: 'pointer', fontFamily: 'inherit' }}>● Smart</button>

```jsx
import { useState } from 'react'
import { createPlayer } from '../api.js'

const SKILL_LEVELS = ['newbie', 'beginner', 'intermediate', 'upper_intermediate', 'advanced']

function fmtWait(s) {
  if (!s) return '0m'
  const m = Math.floor(s / 60)
  return m < 60 ? `${m}m` : `${Math.floor(m/60)}h ${m%60}m`
}

export default function StatsSidebar({ stats }) {
  const [showAdd, setShowAdd] = useState(false)
  const [form, setForm] = useState({ name: '', skill_level: 'intermediate' })
  const [saving, setSaving] = useState(false)

  async function addPlayer(e) {
    e.preventDefault()
    setSaving(true)
    await createPlayer(form)
    setForm({ name: '', skill_level: 'intermediate' })
    setSaving(false)
    setShowAdd(false)
  }

  const cell = { background: '#0f172a', border: '1px solid #1e293b', borderRadius: 4, padding: '6px 8px', textAlign: 'center', marginBottom: 4 }
  const inp = { background: '#0a0f1a', border: '1px solid #1e293b', borderRadius: 3, color: '#f1f5f9', padding: '4px 6px', fontSize: 10, fontFamily: 'inherit', width: '100%' }

  return (
    <div style={{ padding: '8px 8px', fontFamily: 'inherit', fontSize: 10, display: 'flex', flexDirection: 'column', gap: 4 }}>
      <div style={{ color: '#1e293b', fontSize: 7, textTransform: 'uppercase', letterSpacing: 1, marginBottom: 2 }}>Session</div>

      <div style={cell}>
        <div style={{ color: '#334155', fontSize: 7 }}>Players</div>
        <div style={{ color: '#f1f5f9', fontSize: 18, fontWeight: 700, lineHeight: 1.2 }}>{stats?.player_count ?? 0}</div>
      </div>
      <div style={cell}>
        <div style={{ color: '#334155', fontSize: 7 }}>Matches</div>
        <div style={{ color: '#f1f5f9', fontSize: 18, fontWeight: 700, lineHeight: 1.2 }}>{stats?.match_count ?? 0}</div>
      </div>
      <div style={cell}>
        <div style={{ color: '#334155', fontSize: 7 }}>Avg Wait</div>
        <div style={{ color: '#fbbf24', fontSize: 15, fontWeight: 700, lineHeight: 1.2 }}>{fmtWait(stats?.avg_wait_seconds)}</div>
      </div>

      {stats?.leaderboard?.length > 0 && (
        <div style={{ background: '#0f172a', border: '1px solid #1e293b', borderRadius: 4, padding: '6px 8px', marginBottom: 4 }}>
          <div style={{ color: '#1e293b', fontSize: 7, textTransform: 'uppercase', marginBottom: 4 }}>Wins Today</div>
          {stats.leaderboard.map((p, i) => (
            <div key={p.player_id} style={{ color: i === 0 ? '#f1f5f9' : '#64748b', fontSize: 9, marginBottom: 2 }}>
              {['🥇','🥈','🥉','4.','5.'][i]} {p.name} · {p.wins}W
            </div>
          ))}
        </div>
      )}

      <button
        onClick={() => setShowAdd(v => !v)}
        style={{ background: '#0f172a', color: '#475569', border: '1px solid #1e293b', borderRadius: 3, padding: '4px', fontSize: 9, cursor: 'pointer', fontFamily: 'inherit', marginTop: 'auto' }}
      >
        + Add Player
      </button>

      {showAdd && (
        <form onSubmit={addPlayer} style={{ display: 'flex', flexDirection: 'column', gap: 4 }}>
          <input placeholder="Name" required style={inp} value={form.name} onChange={e => setForm(f => ({...f, name: e.target.value}))} />
          <select style={inp} value={form.skill_level} onChange={e => setForm(f => ({...f, skill_level: e.target.value}))}>
            {SKILL_LEVELS.map(s => <option key={s} value={s}>{s.replace('_',' ')}</option>)}
          </select>
          <button type="submit" disabled={saving} style={{ background: '#166534', color: '#dcfce7', border: 'none', borderRadius: 3, padding: '4px', fontSize: 9, cursor: 'pointer', fontFamily: 'inherit' }}>
            {saving ? '...' : 'Add'}
          </button>
        </form>
      )}
    </div>
  )
}
```
